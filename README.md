## Лабораторная работа № 3. Vue 3: каркас и три экрана

### Описание проекта

Клиентская часть учебной информационной системы учёта заявок на устранение простоев насосного оборудования ПАО «Сургутнефтегаз».

Приложение разработано с использованием Vue 3, JavaScript и Vite.

### Реализованные экраны

- Список заявок с демонстрационными данными.
- Форма создания заявки.
- Форма входа в систему.

На данном этапе сервер и база данных не подключены. Новые заявки хранятся в памяти приложения.

### Запуск приложения

```bash
cd frontend
npm install
npm run dev
```

Откройте адрес Vite, обычно http://localhost:5173.
