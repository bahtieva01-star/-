# Архитектура информационной системы

## 1. Назначение

Архитектура проекта построена по трёхуровневой схеме:

1. клиентская часть — Vue 3;
2. серверная часть — ASP.NET Core;
3. база данных — PostgreSQL.

Браузер пользователя взаимодействует с сервером приложения по HTTP. Сервер приложения выполняет бизнес-логику, проверяет права доступа и работает с базой данных.

Прямого соединения браузера с PostgreSQL нет.
