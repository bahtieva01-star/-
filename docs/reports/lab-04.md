**Студент:** Бахтиева Аделина Альфредовна

### Цель работы

Изучить создание компонентов во Vue 3 и настройку маршрутизации между страницами приложения.

### Выполненные работы

1. Настроена маршрутизация с помощью Vue Router.
2. Созданы страницы списка заявок, создания заявки и входа в систему.
3. Создан компонент `AppHeader.vue` для отображения шапки приложения и навигации между страницами.
4. Создан компонент `TicketTable.vue` для отображения заявок в виде таблицы.
5. Создан файл `ticketsStore.js` для хранения общего массива заявок в памяти браузера.
6. Настроен компонент `App.vue`, в котором шапка приложения отображается отдельно от содержимого текущей страницы.
7. Реализованы переходы между страницами `/`, `/new` и `/login`.

### Результаты работы

В приложении отображается список заявок на устранение простоев насосного оборудования. Пользователь может перейти к форме создания заявки или на страницу входа в систему.

Проверена работа маршрутов и компонентов. Страницы открываются, навигация работает корректно, а список заявок отображается в таблице.

В ходе лабораторной работы изучены компоненты Vue 3 и маршрутизация с помощью Vue Router. Создана структура пользовательского интерфейса приложения для учёта заявок на устранение простоев насосного оборудования. Данные заявок хранятся в общем массиве в памяти браузера.
