# Лабораторная работа № 7. Создание ASP.NET Core Web API

**Цель работы:** создать серверную часть информационной системы учёта и обработки заявок на устранение простоев насосного оборудования.

В ходе работы был создан проект ASP.NET Core Web API на языке C#. Настроены контроллеры и сервисы для обработки заявок.

Реализованы следующие методы API:
- GET — получение списка заявок;
- GET — получение заявки по идентификатору;
- POST — создание новой заявки;
- PATCH — назначение исполнителя;
- PATCH — изменение статуса заявки.

Также реализованы проверки доступности сервера и получение информации о приложении. Для тестирования API использовался Swagger.

Проверена успешная сборка проекта и работа основных методов API.

**Вывод:** в ходе лабораторной работы создан каркас серверной части информационной системы. Реализованы основные операции для работы с заявками и проверена их работа через Swagger.
