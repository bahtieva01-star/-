# Лабораторная работа № 6. Vue 3: клиент API и mock

## Цель работы

Разработать клиентский модуль для взаимодействия с API, реализовать имитацию серверных запросов и обработку различных состояний интерфейса.

## Выполненные работы

1. Создан модуль `src/api/tickets.js` для получения и создания заявок.
2. Реализован mock API в файле `src/api/mockTickets.js`.
3. Добавлена загрузка заявок при открытии страницы.
4. Реализованы состояния загрузки, пустого списка и ошибки.
5. Подключено создание заявок через API.
6. Реализована блокировка кнопки на время отправки формы для предотвращения повторных запросов.
7. Добавлена обработка ошибок с кодами 400 и 500, а также ошибок соединения.
8. Создан файл `.env.example` с адресом API. Локальный файл `.env` исключён из Git.

## Проверка работы

При использовании mock API список заявок загружается, а новая заявка создаётся и отображается в таблице.

При ошибке 500 отображается сообщение о сбое сервера. При отсутствии соединения пользователь получает сообщение об ошибке отправки.

## Вывод

В ходе лабораторной работы реализован клиентский модуль API с mock-режимом. Настроены загрузка и создание заявок, отображение состояний интерфейса и обработка ошибок.
