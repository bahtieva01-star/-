# Лабораторная работа № 5
## Vue 3: форма и список в памяти

**Студент:** Бахтиева Аделина Альфредовна  
**Группа:** ТРИС-3-23

### Цель работы

Реализовать создание заявок на устранение простоев насосного оборудования с помощью формы Vue 3, добавить проверку введённых данных и хранение записей в памяти браузера.

### Выполненные работы

1. Реализована форма создания заявки с полями названия проблемы, номера насоса и описания.
2. Добавлена проверка корректности введённых данных.
3. Реализован вывод сообщений об ошибках рядом с соответствующими полями.
4. Создана функция добавления заявки в общий массив данных.
5. После успешного создания заявки форма очищается, а пользователь возвращается к списку заявок.

### Результаты проверки

1. При вводе короткого названия `abc` и описания `сломался` отображаются сообщения об ошибках. Заявка не создаётся.
2. При вводе корректных данных заявка успешно добавляется в таблицу и получает собственный номер.
3. После обновления страницы клавишей F5 созданная заявка исчезает, а исходные заявки остаются в списке.

### Вывод

В ходе лабораторной работы реализованы форма создания заявки, проверка введённых данных и добавление записей в общий массив Vue. Проверки показали, что форма работает корректно. Данные хранятся только в памяти браузера, поэтому новые заявки не сохраняются после обновления страницы. Сохранение в базе данных в рамках данной лабораторной работы не реализовано.
