# API-контракт

## Назначение

API предназначен для взаимодействия клиентской части приложения на Vue 3 с серверной частью на ASP.NET Core.

Браузер не обращается к PostgreSQL напрямую. Все операции с данными выполняются через ASP.NET Core API.

Главный объект API — заявка на устранение простоя насосного оборудования (`DowntimeRequest`).

Базовый путь API:

`/api/downtime-requests`

---

## 1. Основные правила API

API работает по HTTP.

Клиент Vue отправляет запросы в ASP.NET Core.

ASP.NET Core:

- принимает HTTP-запрос;
- проверяет авторизацию пользователя;
- проверяет права роли;
- проверяет данные;
- выполняет необходимые операции с PostgreSQL;
- возвращает HTTP-ответ клиенту.

PostgreSQL не доступен браузеру напрямую.

---

## 2. Получение списка заявок

### GET `/api/downtime-requests`

Получение списка заявок.

### Тело запроса

Отсутствует.

### Успешный ответ

HTTP `200 OK`.

Если заявки существуют, сервер возвращает массив объектов.

Если заявок нет, сервер возвращает пустой массив `[]`, а не ошибку `404`.
